# Chart buffer and navigation corrections

Implementation of the approved [buffer design](../plans/2026-11-08-chart-navigation-buffer-design.md), following the [navigation investigation](2026-11-08-chart-navigation-investigation.md). Author verification; no independent Astra review is claimed.

Live preparation now requests at least 1,440 completed M1 trading candles where verified history permits, expanding over closed sessions/weekends and retaining detector initialization requirements. Live price views can return that buffer; ordinary analysis views retain their default 500-candle response. Historical price reads assemble up to 1,440 M1 candles through bounded 500-candle pages. Higher timeframe reads cover the corresponding trading duration or a useful minimum 90-candle display. Immutable requests are coalesced/cached with 16-window eviction.

The displayed price buffer merges ordered, overlapping price pages, with a 6,000-candle bound. Feed/connection, instrument, timeframe, explicit source selection and replay identity scope the buffer. History responses from an obsolete source/timeframe cannot seed a new buffer. Replay prices remain filtered by revealed availability even when a previous read cached later candles. Ordinary earlier navigation extends prices; an explicit Move to opens/focuses the requested view separately. Returning live waits for a coherent latest-window response rather than reusing a stale historical response as current live data.

Calculated detector events and component frames are retained alongside prices, keyed by analysis identity and display timeframe. Earlier price responses cannot erase known swing/detector markers. Historical calculations now expose their component observations for indicator overlays as well as detector events. Evidence is clipped to revealed price availability; expired pre-window occurrences are evicted while ongoing pre-window states are retained. Mixed coverage is labelled as partial rather than implying all markers were lost. Replay UI marker ordinals are rebuilt after merging; immutable source event IDs remain unchanged.

The shared chart rebases a timestamp anchor when prices are prepended or evicted. Data count changes, including removal of a forming candle, no longer reset the visible range. Zoom buttons enter navigation mode and preserve selected spacing during loading. Visible-range changes and resize observations request an earlier buffer near the left edge, then recheck after arrival/busy-state changes. Request guards and explicit failure/boundary states prevent continuous retries. Fit candles remains an explicit fit of the current loaded data. A pending fit survives the forming-to-completed data transition before panning starts. Unchanged polling responses no longer replace the entire candle series or reset its viewport; forming-price-only changes update the last candle. Zoom density is bounded to keep the requested display within the retained-buffer capacity.

Raw provider session markers were removed: the first observation has no preceding context proving a session boundary, and internal `provider` names are shown as Trading session only at observed session changes. This changes presentation, not analytical calendar/session identities. Loading/failure/boundary messages sit beside chart navigation, with existing retry/cancel actions available. Switching from historical preparation to live cancels the old preparation before changing mode.

Price acquisition does not change detector policy or rewind the running live engine. Historical analysis still follows live/manual/always configuration and the chart's displayed period. Hidden-tab connection/rendering rules remain in place. No schema migration or installed-data deletion is needed.

Verification includes calendar-aware initialization across a weekend; bounded historical paging across a closure; viewport prepend/eviction/forming-candle geometry; duplicate-free overlap; truthful session markers; and Chrome regressions for initial buffer, scale/anchor preservation, automatic older loading, delayed publication without point focus, and returning to the live edge. Existing smoke fixtures now declare their actual feed ranges and known limits rather than implying provider history outside their mocked prices. Earlier-history expectations retain later loaded candles instead of expecting replacement windows.
